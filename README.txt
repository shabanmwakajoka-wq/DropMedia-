MEDIADROP PRO — MONETIZATION-READY STATIC WEB APP

Included:
- index.html
- style.css
- script.js

Features:
- Responsive modern UI
- Home/menu navigation
- Direct media URL downloader demo
- Downloads and session history
- Dark/light mode
- Premium pricing/upsell page
- Ad placement placeholders
- Privacy and Terms pages
- Local session storage

HOW TO PUBLISH:
1. Extract the ZIP.
2. Upload the files to GitHub Pages, Cloudflare Pages, Netlify, or another static host.
3. Connect a custom domain if desired.
4. Replace the ad placeholders with code supplied by your approved advertising network after approval.
5. Connect a legitimate payment provider to the Premium button if you want subscriptions.

IMPORTANT:
The included downloader is browser-only. It does not bypass DRM, login, paywalls, anti-bot systems, or CORS restrictions. It is intended for direct media URLs that the user is authorized to download.

MONETIZATION:
The app contains placeholders, not an active advertising or payment account. Earnings are not guaranteed. Advertising/payment providers have their own approval, policy, geographic, traffic, and payout requirements.

For a full downloader supporting third-party platforms, a backend is required and must comply with the relevant platform terms and copyright law.
